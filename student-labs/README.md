# Student lab files

Reference copies of the files the Docker and AWS drills ask students to create.

The running lab site is the exercise sheet. These files exist so an instructor can hand out a folder, or diff a student's directory against a known-good copy.

```text
student-labs/docker/menu-api/app.py
student-labs/docker/menu-api/Dockerfile
student-labs/docker/menu-api/.dockerignore
student-labs/docker/web/index.html
student-labs/docker/compose.yaml
student-labs/aws/hello.txt
student-labs/aws/boot.sh
```

Students should work in new folders in their home directory (`~/drillbook-git`, `~/drillbook-docker`, `~/drillbook-aws`), not inside this repository.
